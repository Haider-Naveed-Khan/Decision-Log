I chose React with JavaScript and Vite because this is a focused frontend demo with a small data model. React made the interactive states and reusable components straightforward, while Vite provided a fast, lightweight development setup. Although TypeScript was recommended, I chose JavaScript because the project’s limited scope did not justify the additional type definitions and configuration.
I chose Tailwind CSS to keep spacing, colors, typography, and responsive behavior consistent across the landing page and demo. Tailwind still uses CSS underneath, but its utilitybased approach avoided maintaining a large custom stylesheet and made the design system easier to understand and modify.
I deliberately did not build authentication, a backend, database persistence, user management, collaboration, or external integrations because they were outside the brief. Decisions are intentionally stored in memory and reset when the page refreshes.
I limited decision states to Active and Superseded because they clearly answer whether a decision still applies without introducing unnecessary workflow complexity. I also prioritized the landing page, realistic sample content, responsive behavior, and polished interaction states because credibility and clarity were more important than adding a large number of features.
